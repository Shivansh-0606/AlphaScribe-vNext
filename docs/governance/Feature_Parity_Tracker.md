## 🔒 Milestone 3 freeze (2026-08-03)

**Milestone 3 (Frontend Engineering — `frontend/` → `web/` screen build-out) is closed.** Every screen in the frozen Screen Inventory (SCR-01 through SCR-10 — Auth, Workspace Home, AI Access Setup, Company Research, Comparison, Report View, Research Library, Learning) now has a real, live-verified `web/` implementation. Phases 1–8 are complete.

**Closed out immediately before freezing, per explicit direction:**

- **`/docs` — will not be built.** Checked against the frozen specification (`docs/design/05_Screen_Inventory.md`): zero mentions. `/docs` exists only as a legacy 1:1 parity item (`frontend/src/pages/Docs.jsx`, a static developer-docs page — install/API-reference/troubleshooting content, not a product screen). Not required by the frozen spec, so it stays **Not Started** by decision, not by oversight — see §1.
- **`.claude/launch.json` port mismatch — fixed.** It defaulted to port 3000; the project's actual convention (CLAUDE.md, `scripts/run.py`, the backend's `CORS_ORIGINS`) is 3001. Root-caused to `web/package.json`'s `dev` script (`next dev`, no port flag) — fixed there (`next dev -p 3001`) rather than papering over it in `launch.json` alone, so every caller of `npm run dev` gets the right port, not just this one config. Also corrected the same stale-3000 assumption in `web/lib/config/env.ts`'s `NEXT_PUBLIC_APP_URL` default and a comment in `playwright.config.ts`. Full gate re-run clean after the fix: `typecheck`/`lint`/`format:check` clean, 286 Vitest tests passing across 62 files.

**What this freeze does NOT mean:**

- **Not the same as the "Migrated" parity gate.** Every feature built in Phases 1–8 is marked **In Progress** in the tables below, not Migrated — real and live-verified, but not yet through the deeper end-to-end hardening pass the Governing Decision requires. The Legacy Frontend Removal Plan stays blocked until every row in §1–§5 reads Migrated, independent of this freeze.
- **Not a statement that Learning is feature-complete.** Learning's backend (retrieval, prompting, source generation behind the Phase 8 contract in `web/features/learning/integration/schemas.ts`) is unimplemented — explicitly deferred to a separate Backend & AI phase, not part of Frontend Engineering's Milestone 3 scope.
- **Not a git commit.** None of the Phase 2–8 work is committed yet; that decision remains separate from this freeze.

Freezing here means: **no further Milestone 3 phases will be opened.** Any subsequent frontend work (the Migrated-parity hardening pass, revisiting `/docs`, etc.) is new scope, tracked as its own initiative, not a Milestone 3 phase.

## Governing decision (effective 2026-07-22)

- `web/` (Next.js 15) is the only active development frontend. All new feature work happens there.
- `frontend/` (CRA) is now a **legacy reference implementation** — read-only. No new features. Only critical bug fixes, and only if absolutely necessary.
- `frontend/` is **not** to be deleted until every row below reaches **Migrated** and passes validation.
- When this tracker reaches 100% and validation passes, a **Legacy Frontend Removal Plan** goes to the CTO for approval before any deletion. Until then, Repository Modernization Phase 3 (removing `frontend/`) stays paused.

## How to read this tracker

**Status values:**

- **Not Started** — no corresponding code exists in `web/` yet, not even scaffolding.
- **Scaffolded** — the frozen IA-domain folder/README/typed contract exists in `web/features/` or `web/lib/`, but no working UI or logic.
- **In Progress** — partial implementation exists in `web/`.
- **Migrated** — full functional parity in `web/`, verified working end-to-end.

**Current overall status: 2 of 16 user-facing routes migrated (Signup, AI Access Setup). Auth (login/forgot-password/settings), the authenticated app shell, and the core research workflow (NewReport/Ingest/ReportView-brief/SSE streaming/citations, Financials/Filings/AI Insights/Export as of Phase 4A–4D, the standalone Report View — SCR-10 — as of Phase 5, the Research Library list — SCR-09 — as of Phase 6, and Comparison — SCR-07 — as of Phase 7) are all In Progress. `/docs` is the only remaining Not Started row within §1–§5. Learning (SCR-08, §6) is now In Progress too, as of Phase 8 — frontend UI/contract complete, real backend implementation deliberately deferred to a separate Backend & AI phase (a different split than every prior phase, by explicit direction, not a scoping shortcut).**
