## Self-maintenance

When you notice this file is out of date — a referenced doc moved/renamed,
a new major doc category appears in docs/, or the project's active phase changes —
propose an update to this file (.hermes.md) yourself. Always ask for approval
before writing the change.

## Status queries

When asked about project status or progress:

1\. Read the Milestones table in docs/roadmap.md.

2\. Cross-reference against `git log --since="2 weeks ago"` — flag any

&#x20;  milestone marked in-progress with no matching recent commits.

3\. Never mark something "done" yourself — only report what the table says,

&#x20;  and flag discrepancies for Shivansh to resolve, don't resolve them yourself.
